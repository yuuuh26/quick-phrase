# QUICK PHRASE v1.0.0

よく使う文章を大きなボタンに登録して、ワンクリックでコピーするWebアプリです。Windows 11 / Chromeを主対象、Android Chromeに対応したレスポンシブUIです。

## 主な機能

- 表示名とコピー本文を分離した定型文の登録・編集・削除
- ピン留め、手動順（↑ ↓）、使用回数順、最近使った順、名前順
- カテゴリ追加・名前変更・削除・上下移動、未分類への移動
- 表示名・本文・メモ・カテゴリのリアルタイム検索、本文プレビュー
- 使用回数・最終使用日時、ライト・ダーク・OS自動テーマ、ボタンサイズ
- IndexedDBへの保存、JSON完全バックアップ、追加・全置換インポート
- 15回のデータ変更でバックアップ通知（コピー・設定変更は回数に含めない）
- PWAインストール、初回キャッシュ完了後のオフライン操作
- アカウント・外部API・外部ライブラリ・アクセス解析なし

## GitHub Pagesで公開

1. GitHubで `quick-phrase` リポジトリを作成します。
2. このフォルダ内のファイル（iconsフォルダと `.nojekyll` を含む）をmainブランチ直下へアップロードします。
3. リポジトリの **Settings → Pages → Build and deployment** で **Deploy from a branch**、**main / (root)** を選んで保存します。
4. 公開URL：`https://yuuuh26.github.io/quick-phrase/`

公開するソースには利用者が登録した文章は含まれません。登録内容は端末内にのみ保存されます。

## PWAとして追加

Windows Chrome：アドレスバーのインストールアイコン、またはChromeメニューから「ページをアプリとしてインストール」を選択します。Android Chrome：メニューの「ホーム画面に追加」からインストールします。Chromeのバージョンにより表示名は異なります。

Windowsではスタートメニューやタスクバーから起動できます。カードをクリックしたら、目的の入力欄へ移動して **Ctrl + V**。スマホでは入力欄を長押しして貼り付けます。

## データとバックアップ

DB名 `quick-phrase-v1`、バージョン1。`phrases`・`categories`・`settings` ストアを使用します。他のアプリのDBやキャッシュを削除しません。複数タブの更新はIndexedDBのトランザクションで直列化し、BroadcastChannelで表示へ反映します。

**設定 → バックアップを保存（JSON）** で定型文・カテゴリ・並び順・固定状態・使用回数・日時・メモ・色・アイコン・設定をまとめて保存します。ダウンロードされたことを確認してください。

**設定 → インポート** で追加または全置換を選択します。追加は定型文IDを再生成し、同名カテゴリを統合して既存のデータを残します。全置換は確認後に1トランザクションで復元します。書き込み失敗時は全変更が取り消されます。JSON形式・参照ID・型・件数を検証し、20MBを超えるファイルは受け付けません。

定型文の表示名120文字、本文100,000文字、メモ10,000文字、アイコン16文字、カテゴリ名80文字まで。インポート最大20,000件・カテゴリ2,000件。本文の改行・先頭末尾の空白は維持します。

## 注意事項

- ブラウザのデータ削除、端末故障、プライベートモード終了などでデータが消える場合があります。永続保存のリクエストだけで消失を完全には防げません。定期的にJSONを保存してください。
- PCとスマホ、Chromeの異なるプロファイル間でデータは自動同期されません。JSONで移せます。
- Clipboard APIにはHTTPSまたはlocalhostが必要です。index.htmlをダブルクリックして開く運用は対象外です。
- コピー失敗時は本文プレビューから手動で選択してコピーできます。
- IndexedDBは暗号化保管庫ではありません。同じGitHub Pagesオリジン内の他アプリや同じ端末の利用者からの隔離を保証しません。
- オフライン表示は画面下部の「オフラインで使用できます」を確認してから利用してください。初回訪問には通信が必要です。
- Service Worker更新は現在の画面を閉じ、次に起動したときに反映します。新バージョンを出すときは `sw.js` のキャッシュ名を変更してください。
- v1.0では別サイトへの直接入力、Chrome拡張連携、クラウド保存、テンプレート変数を実装していません。

## ローカル開発

このフォルダで `python3 -m http.server 8080` を実行し、`http://localhost:8080/` をChromeで開きます。ビルドやnpmインストールは不要です。

## データ形式

バックアップは `{app:"quick-phrase", schemaVersion:1, exportedAt, phrases, categories, settings}`。UIと独立したJSON互換データです。将来の拡張機能でもこのバックアップ形式を再利用できます。設定の `initialized` は初期サンプルの再作成を防ぐフラグです。
